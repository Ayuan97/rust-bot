CHROME // MANUAL INSTALL

在 Chrome 安装 Rust+ 凭证助手

Chrome 应用商店版本即将上架。在此之前，按下面步骤手动安装即可正常使用，整个过程约 1 分钟。

⬇ 下载插件包 rust-credentials-helper.zip
1

下载并解压

点上方按钮下载插件包，解压到一个固定的文件夹（之后别删它，删了插件会失效）。

2

打开扩展管理页

在 Chrome 地址栏输入 chrome://extensions 回车。

3

打开开发者模式

页面右上角把「开发者模式 / Developer mode」开关打开。

4

加载插件

点左上角出现的「加载已解压的扩展程序 / Load unpacked」，选择第 1 步解压出来的 browser-extension 文件夹。

5

固定到工具栏

点地址栏右侧的拼图图标 🧩，把「Rust+ Credentials Helper」固定出来，方便点击。

6

完成

回到配对向导，按提示登录 Steam、复制凭证命令即可。

小提示：手动安装的插件，Chrome 每次启动可能弹一次「是否停用开发者模式扩展」的提醒，点「保留」即可，不影响使用。等正式上架商店后，一键安装就没有这个提示了。
